## 1. EzYOLO 标注结果定位

### 1.1 期望与现实

| 项 | 期望 | 现实 |
| --- | --- | --- |
| SQLite DB（EzYOLO 项目文件） | `*.ezyolo` 或 `ezyolo.db` | **不存在**（find `*.sqlite` / `*.db` 零结果） |
| 人工标注 YOLO .txt 标签 | `*/labels/*.txt` 来自人工 | ✅ 存在于 `datasets/Barbell/labels/`（1650）与 `datasets/杠铃片监测/labels/`（408） |
| 自动生成 YOLO .txt 标签 | `*/labels/*.txt` 来自 cv2 | ⚠️ 存在于 `datasets/barbell_dataset/labels/`（728，未人工复核） |
| EzYOLO export zip | `barbell_plate_v1.zip` | **不存在**（scripts/create_barbell_annotations.py 的"下一步"流程尚未执行） |
| EzYOLO 项目配置文件 | `<project>.yaml` 或 `.ezyolo/config.json` | **不存在** |

### 1.2 现有标注位置（按可信度排序）

```text
datasets/Barbell/labels/<video32hex>/<video32hex>_<frame6digit>_POS.txt          # 1650 文件 ← 人工标注（可信）
datasets/杠铃片监测/labels/<video32hex>_<frame6digit>.txt                          # 408 文件 ← 人工标注（可信）
datasets/barbell_dataset/labels/<video32hex>/<video32hex>_<frame6digit>[_RB].txt # 728 文件 ← cv2 自动生成（未复核）
datasets/owlvit_pseudo/labels/owlvit_<weight>_<mcvs>_<frame>_<hash>.txt            # 58 文件 ← OWL-ViT 伪标签（失败级）
```

**结论**：

- `Barbell/` 和 `杠铃片监测/` 是**唯一可信的人工标注**（总计 2058 张）；
- `barbell_dataset/` 728 张走的是"cv2.Canny 边缘检测 → 写 .txt"**全自动**流程；
- EzYOLO 在 README / create_barbell_annotations.py 的注释里被当作"人工复核工具"提及，但**实际从未调用过**（未发现 `ezyolo_runs/`、无 EzYOLO 项目文件）；
- SESSION_HANDOFF_20260911 §五 提到 `barbell_dataset/ ← 728 张已标注帧（EzYOLO 标注中）`，描述不准确——实际是"自动生成中"，人工审核环节被跳过。

### 1.3 标注生成脚本（事实来源）

- `scripts/create_barbell_annotations.py` (11581 bytes，2026-09-12)
  - 算法：`cv2.Canny` + 水平膨胀 + `cv2.findContours` → 宽高比 ≥ 1.5 的最大轮廓 → 转换 YOLO 相对坐标
  - 蹲底帧（`_BOTTOM` 或 `_RB`）回退到下半图最低候选
  - 输出：1 类 `plate` (class_id=0)，按 85/15 划分（seed=42）

### 1.4 推荐下一步（**待 Daniel 决策**）

- **选项 A**（最低成本）：维持现状，标注已可直接训练 best.onnx（已证 28/34 配对率）。
- **选项 B**（中成本）：把 728 个 .txt + 728 张图打包成 `barbell_plate_v1.zip`，由人工在 EzYOLO 中复核后导出正式版（EzYOLO 输出 SQLite 项目文件 + 标准化 zip）。
- **选项 C**（高成本）：直接接入 Roboflow 或 Label Studio 工作流，跳过 EzYOLO。

> 在 Daniel 决策前**不要删除** `datasets/barbell_dataset/`，它是 best.onnx 训练的源。

### 7.2 核心风险：best.onnx 训练数据的可信度错位

  - **多片场景身份歧义**（与 102.5kg +0.77 bias 同源）

- 人工标注则不存在这些问题——Daniel 看到每张图后画的框

**best.onnx 表现"超预期"的解释**（28/34 配对）：

- cv2 启发式在**画面清晰 + 工作片显著**的场景（如 30/50/80kg 单片）足够用
