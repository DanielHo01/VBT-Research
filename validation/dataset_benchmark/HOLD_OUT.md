# 验收集（HOLD OUT SET）—— Phase 0 基线

本目录下的 34 条视频（`raw_videos/`）为**验收集**，永久封存：

## 封存规则（非协商）

1. **永不补标**：不得为此目录下的视频添加或修改标注
2. **永不训练**：不得将此目录的视频用于模型训练
3. **永不调参**：不得根据此目录的跑分结果调整算法参数
4. **难例外采**：缺失检测/漏检/跳变的难例必须从**新采集**视频补充

## 用途约束

| 用途 | 是否允许 |
| ------ | --------- |
| 离线检测基线（Phase 0） | ✅ 允许 |
| 人工过审 / overlay 可视化 | ✅ 允许 |
| 算法调参 / 超参搜索 | ❌ 禁止 |
| 模型训练 / 微调 | ❌ 禁止 |
| 标注补充 | ❌ 禁止 |

## 入口条件（Phase 0 → Phase 1）

```
VDR_present >= 99.5%  AND
Track_Loss == 0        AND
34/34 overlay 人工过审全部通过
```

- 增强检测模型（独立于验收集）
